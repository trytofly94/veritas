## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Browser → `/archive` | Untrusted client requests an authenticated HTML page. Session cookie HMAC is the auth artifact. |
| `/archive` handler → SQLite manifest | Server-side trusted boundary. No user input reaches the SQL query. |
