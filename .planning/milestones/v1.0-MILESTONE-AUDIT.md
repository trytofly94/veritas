### Blocker B-3 — Alpine.js init race on archive-detail page

- **Location:** `src/views/archive-detail.ts:104-105`
- **Symptom:** "Integrität prüfen" button text is empty, click throws `run is not defined`, verify result never appears in the page. 11 ReferenceErrors at page load.
- **Root cause:** `<script defer src="/static/alpine.min.js">` is loaded BEFORE `<script defer src="/static/archive-detail.js">`. With `defer`, both scripts execute in document order after DOM-ready; Alpine fires its `alpine:init` event during its own initialization, before `archive-detail.js` has registered its `Alpine.data('verifyIntegrity', …)` and `Alpine.data('copyState', …)` listeners.
- **Why iter-1/iter-2 missed it:** iter-1 verified the API endpoint via curl (it works — returns `{ok:true}`), not the browser handler. iter-2 was static grep only.
- **Reference fix:** `src/views/upload.ts:27-29` already loads the page-specific script BEFORE alpine.min.js and has an explicit comment about the ordering requirement. archive-detail.ts does not follow the same pattern.
- **Fix:** swap the two `<script>` tags so `archive-detail.js` loads before `alpine.min.js`.
